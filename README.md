# Find@ API — OpenAPI Specification

Official OpenAPI 3.1 specification for the Find@ API.

Find@ provides programmatic access to:
- Smart short links
- Bio pages
- QR codes
- Branded domains
- Campaigns, channels, pixels
- Analytics metadata

## Files
- openapi.yaml — source of truth
- openapi.json — generated variant

## Usage
- Import into Postman
- Generate SDKs
- Power AI agents and automations
